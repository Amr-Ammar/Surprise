A LITTLE SURPRISE — WEBSITE FILES

1) Open this folder in Visual Studio Code.
2) Keep index.html in the main folder.
3) Put your 10 photos in the images folder and name them:
   photo1.jpg, photo2.jpg, ... photo10.jpg
4) Put your audio file in the main folder and name it song.mp3.
   Use an audio file you have permission to use. The browser starts it after
   the visitor presses OPEN YOUR SURPRISE.
5) Open index.html in a browser (or use the VS Code Live Server extension).

EDITING:
- Opening title/text: search for "Hey, My Love."
- Main birthday heading: search for "Happy Birthday,"
- Main paragraph: search for "Happy birthday, my love."
- Photo captions: edit the text inside each <figcaption>.
- Final message: search for "I don't know what the future"
- Signature: search for "With all my love"

To publish for free:
- Create a free account on Netlify.
- Use Netlify's manual deploy / drag-and-drop option and upload this whole project
  folder (or its ZIP). Keep the images folder and song.mp3 together with index.html.
- Netlify will give you a shareable website link.

NOTE: A song file is not included. Add your own song.mp3 file to the project.
